# 一行一句，写得简单、贴近小孩日常词汇。

# —— 灰姑娘
从前有一个心地善良的小姑娘。
她每天都要做很多家务。
有一天她遇见了一位仙女。
仙女把南瓜变成了一辆马车。
她在午夜之前赶回了家。
水晶鞋掉在了台阶上。
王子带着鞋子找到了她。

# —— 白雪公主
山里住着七个小矮人。
白雪公主和小矮人成了好朋友。
小鸟在窗前唱着歌。
苹果掉在了草地上。
她在森林里跑啊跑。

# —— 小红帽
小女孩戴着红色的帽子去看外婆。
路边的野花开得很美。
她在森林里采了一束花。
猎人救出了外婆和小红帽。

# —— 三只小猪
三只小猪盖了三间房子。
第一只小猪用稻草盖房子。
第二只小猪用木头盖房子。
第三只小猪用砖头盖房子。
大灰狼把稻草房子吹倒了。
砖头房子结实又安全。

# —— 丑小鸭
湖边有一只灰灰的小鸭子。
他和别的鸭子长得不一样。
冬天到了湖面结了冰。
春天来了他变成了美丽的天鹅。

# —— 龟兔赛跑
小兔子和乌龟比赛跑步。
小兔子跑得很快很快。
乌龟一步一步地向前爬。
小兔子在树下睡着了。
乌龟先到了山顶。

# —— 拇指姑娘
花朵里走出一个小小的姑娘。
她只有拇指那么大。
燕子带着她飞过了大海。
春天的花园开满了花。

# —— 卖火柴的小女孩
寒冷的夜里下着大雪。
小女孩点亮了一根火柴。
火光里出现了温暖的火炉。
她梦见了奶奶和她在一起。

# —— 皇帝的新装
两个骗子说要做一件神奇的衣服。
大臣们都假装看见了。
一个小男孩说他什么也没看见。
人们终于笑了起来。
